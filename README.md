#  Laptop Price Predictor

A Machine Learning regression project that predicts the price of a laptop based on its specifications.

The project includes a Streamlit web application and is containerized using Docker. The Docker image is published on Docker Hub so the application can be pulled and run easily on any machine with Docker installed.
